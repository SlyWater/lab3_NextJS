# Лабораторная работа 3

```sh
npm ci
npm run dev
```

Для карты требуется переменная `NEXT_PUBLIC_YANDEX_MAPS_API_KEY`.

Сборка и запуск: `npm run build`, `npm start`.

Страницы: `/` — ФИО и группа, `/content` — карта, `/petto` — Petto, `/communities` — сообщества.

Сообщества сохраняются на сервере в `data/communities.json`. На Vercel JSON-файл хранится в подключённом Vercel Blob.
